# Plant Library (Drupal 11)

A plant and herb library built with Drupal 11 and DDEV.

## Requirements

- DDEV and a Docker provider

## Set up locally

  git clone git@github.com:YOUR-USERNAME/plant-library-drupal.git
  cd plant-library-drupal
  ddev start
  ddev composer install
  ddev launch

## What is iside

- A plant content type with Latin name, sun, water, sowing months, plant types and image
- A plant type taxonomy
- A plants view at /plants
- Configuration exported to config/sync
